# Ready2Go Learning frontend — v2.0.0

Static, installable PWA built with HTML, CSS and vanilla JavaScript. Publish the contents of `app/` at the site root using the parent deployment script. `js/content-config.js` is generated by the script to point to the published Cloudflare Worker.

Local bundled content: 1,090 original practice questions over 25 subject packs. English and Mathematics: 70 each; Physics, Chemistry and Biology: 50 each; remaining 20 packs: 40 each. Expert review is required before representing questions as verified exam content or publishing packs to R2.

Offline status only appears once the full service-worker precache succeeds. Install remains controlled by the browser. Do not place server secrets in frontend files.
